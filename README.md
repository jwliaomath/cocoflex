# CoCoFlex

CoCoFlex models continuous conformational variation from cryo-EM particle images by steering a pretrained structure generator to produce atomic conformations.

- [Preprint on Langtaosha](https://doi.org/10.65215/LTSpreprints.2026.11.26.000403)
- [CoCo platform](https://cocoproject.org.cn/)
- [Structures, density maps, and numerical source data on Zenodo](https://doi.org/10.5281/zenodo.24097400)

Source code and documentation are being prepared. Updates will be posted here.
